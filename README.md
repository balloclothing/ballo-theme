# Ballō — Tema de Shopify

Tema propio de la tienda online de **Ballō**: camisetas premium y minimalistas para hombre, en algodón 100%.

- Basado en el [Skeleton Theme oficial de Shopify](https://github.com/Shopify/skeleton-theme), versión `v1.0.0` (Online Store 2.0, con secciones y plantillas JSON).
- Hecho en Liquid, sin apps de terceros.

## Vista previa local

```bash
shopify theme dev --store TU-TIENDA.myshopify.com
```

## Estructura

```
assets/     CSS, JavaScript e íconos
blocks/     Bloques reutilizables
config/     Ajustes del tema (colores, tipografía)
layout/     Plantilla base de todas las páginas
locales/    Textos traducibles (es.default.json)
sections/   Secciones editables desde el editor de temas
snippets/   Fragmentos de código reutilizables
templates/  Plantillas de cada tipo de página
```
